01｜課題

そのタイプ作成、まだ手作業ですか。

タイプを一つ用意するために、部材を探し、仕様を読み解き、ファミリを編集し、動作を確認し、名前を整える。
小さく見える作業の積み重ねが、設計の時間を圧迫しています。

これまでのタイプ作成

  1. 必要な仕様を整理
  2. 使えそうな既存ファミリを探す
  3. 社内で作るか・外注か・流用かを判断
  4. 参照面・拘束・数式を編集
  5. 表示・集計・寸法変更を確認
  6. 名前を付けてプロジェクトへ登録
  7. 変更のたびに、再編集・再確認

Arch-LINC BIM Standard

  1. 各部材の仕様を選ぶ
  2. 必要な仕様を選ぶ
  3. タイプを生成・反映

専門的な制作工程を、
迷わない選択操作へ。

02｜解決方法

形状を「作る」から、仕様を「選ぶ」へ。

必要なのは、ファミリ編集の専門知識ではありません。
形式・枠・沓摺・パネル・寸法など、建具の用語と必要な仕様が分かれば、選択だけでタイプを生成できます。

  • 担当者ごとに作り方が違う同じ手順で標準タイプを生成
  • タイプ名と実際の仕様がずれる選んだ仕様から名前とパラメータを自動反映
  • 似たタイプが案件ごとに増える同じ条件の重複作成を抑制
  • 2D・3D・集計情報がバラバラ形状・表示・属性へ一貫して反映
  • 設計変更のたびに作り直す選択を切り替えて更新

03｜実例 ① ドア

ドアファミリ、
1つずつ作っていませんか？

枠も、沓摺も、開き勝手も。必要な仕様が増えるほど、タイプ作成と変更の手間も増えていきます。
タイプ生成なら、建具用語を選ぶだけで標準タイプへ。

  1. 形式選択してください片開き戸片開き戸両開き戸親子開き戸

  4. パネル選択してください窓＋ガラリ窓窓＋ガラリガラリ

03｜実例 ② 窓

窓ファミリ、
仕様ごとに作り分けていませんか？

形式も、枠も、ガラスも。条件が増えるほど、作り分けと変更の手間も増えていきます。
窓の仕様を選ぶだけで、ジェネリックファミリ準拠の標準タイプへ。

  1. 枠タイプ選択してくださいRCRCALCPB
  2. 連窓数選択してください2123
  3. 段数選択してください1123
  4. ガラス選択してください複層ガラス単板ガラス複層ガラス網入りガラス
  5. 幅・高さ選択してくださいW1800 H1200W1690 H1370W1800 H1200W2600 H1200

生成タイプ名AW-1

03｜実例 ③ シャッター

シャッターファミリ、
案件ごとに作り直していませんか？

ケース、スラット、ガイドレール、開口寸法。部材が多いシャッターも、同じ選択操作で仕様を整理し、標準タイプとして生成します。

  1. ガイド選択してください標準ガイドレール標準ガイドレール埋込ガイドレール
  2. ケース選択してください天井付天井付壁付
  3. 形式選択してください軽量シャッター軽量シャッター重量シャッター
  4. 開口寸法選択してくださいW3000 H2500W2500 H2500W3000 H2500W3600 H3000

生成タイプ名軽量_W3000×H2500

04｜使い方

選んで、生成。たった2ステップ。

01

各部材の仕様を選ぶ

パネル・枠・沓摺などを、いつもの建具用語で選択します。

02

タイプ生成・反映

標準の名前と必要なパラメータを持ったタイプがプロジェクトへ。

設計変更にも、そのまま追従

仕様が変わっても、一から作り直す必要はありません。
選んだ仕様を変更して、タイプを再生成・更新します。

05｜チームで使える標準

速さと品質を、同時に。

設計担当

検討のスピードを保つ

必要な建具タイプを早い段階で用意。ファミリ制作ではなく、プラン検討と設計判断に時間を使えます。

BIM推進担当

標準を現場に広げる

同じ生成フローを共有し、専門担当者への依頼集中を抑えながら、運用ルールを定着させます。

管理者

品質のばらつきを抑える

担当者ごとの設定差、独自の命名、似たタイプの増殖を減らし、案件をまたいで品質を管理できます。

タイプ生成は、Arch-LINC BIM Standard の一部です

Revit導入前後に必要な「標準環境」をまとめて提供する、BIM標準化パッケージです。

  • Revitファミリ実務ですぐ使える標準ファミリ（約700点を予定）
  • Revitテンプレートビュー・図面表現・集計表・シート構成
  • 便利ツール（アドイン）タイプ生成、壁タイプ生成、ファミリダウンロードなど
  • オンデマンド動画導入・操作・社内ルールをいつでも学べる
  • マニュアル・導入ガイド初期設定から運用ルールまで整理
  • 導入支援社内テンプレート調整や命名ルール整理をサポート
